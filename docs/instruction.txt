1. 将 APK 放到手机上
--------------------
如果手机支持这张 microSD 卡：
  插入卡片，打开“文件”或“我的文件”，进入存储卡并点击 Fieldwatch.apk。

否则，将 Fieldwatch.apk 复制到手机（USB、网盘或其他文件传输方式），再点击安装。

如果 Android 阻止安装：
  设置 → 应用 → 特殊应用权限 → 安装未知应用
  （Samsung：设置 → 安全与隐私 → 安装未知应用）
  允许用于打开 APK 的应用（文件、Chrome、网盘等）安装，再次点击 Fieldwatch.apk。

Play Protect 可能提示该应用并非来自 Play 商店，这是侧载时可能出现的提示。
只有信任这个 APK 时才选择“仍要安装”。

如果手机已安装上游 Fieldwatch 1.0.4 或更早版本，需先卸载。
这些版本使用不同签名，Android 不允许直接覆盖更新；卸载会清除手机上的应用设置和日志。
本地中文构建若与已安装版本签名不同，同样需要先备份，再卸载安装。

安装完成后，从启动器打开“Fieldwatch 中文版”。


2. 开启系统无线功能
--------------------
首次启动前或启动后，确保系统设置中的以下功能已开启：

  • 位置信息：开启。否则 Android 不会提供 Wi-Fi BSSID 或有效的 BLE 结果。
  • Wi-Fi：开启。
  • 蓝牙：开启。

Fieldwatch 仅监听 Wi-Fi 接入点信标和 BLE 广播，不会加入网络、配对或扫描经典蓝牙。
HC-05 / HC-06 不会出现。


3. 授予 Fieldwatch 所需权限
---------------------------
在“Fieldwatch 需要无线权限”页面点击“授予权限”。

允许以下权限（名称可能随 Android 版本变化）：

  位置信息
    精确位置权限，用于 Wi-Fi 扫描结果和 BLE。
    “设置”中的“为检测记录添加 GPS 标记”默认开启，也使用此权限记录实时位置。
    请启用高精度定位，否则轨迹可能一直为 0 米。

  附近的 Wi-Fi 设备（Android 13+）
    允许 Fieldwatch 执行 Wi-Fi 扫描。

  附近的设备 / 蓝牙扫描和连接（Android 12+）
    用于 BLE 观测。系统协议栈读取部分名称时需要“连接”权限，
    但 Fieldwatch 不会为检测而建立蓝牙连接。

  通知（Android 13+）
    用于持续显示“Fieldwatch 正在扫描”状态，以及可选的关注列表提醒。

如果拒绝任何必要权限，Fieldwatch 会停留在权限页。之后也可手动授予：
  Android 设置 → 应用 → Fieldwatch → 权限。


4. 首次启动检查
----------------
  1. 首次启动显示免责声明和许可证。勾选“我已阅读并同意”，然后点击“继续”。
     完成前不会启动无线扫描。
  2. 完成权限页授权。所有必需权限齐全后才开始扫描。
  3. 出现“Fieldwatch 正在扫描”通知，请保留该通知。
     点击通知中的“停止”，或从最近任务中划掉 Fieldwatch，会结束采集。
  4. “实时”页应显示 Wi-Fi 接入点和 BLE 广播设备。
     顶部显示 Wi-Fi、蓝牙、特征库图标及数量，也可能带有无线状态提示。
  5. 如果两类设备数都一直为零，请检查系统的位置信息、Wi-Fi 和蓝牙，而不只是应用内开关。

首次启动后，为保持扫描：
  • 在 Fieldwatch“设置”中打开“允许后台使用”，进入系统电池页并开启对应选项。
  • 将电池使用设为“不受限制”。部分手机不会直接显示“不受限制 / 已优化 / 受限制”。
    如果只看到“允许后台使用”，点击该行文字而不是开关，进入后再选择“不受限制”。
  • “保持屏幕常亮”默认开启。查看实时列表时建议保持开启；部分手机锁屏后会暂停 BLE。
    将手机放入口袋时可以关闭它。
  • 如果系统有“后台使用限制”或“将未使用的应用置于休眠”，不要让 Fieldwatch 休眠。

尽可能多地采集会增加耗电，完整步骤见用户手册 §4.5：
  开启系统精确位置、Wi-Fi 和蓝牙；授予全部所需权限；
  将电池设为不受限制且不让应用休眠；观测时保持屏幕常亮；使用默认的高性能扫描。
  可选：关闭“开发者选项 → Wi-Fi 扫描节流”，再开启 Fieldwatch 的“加快 Wi-Fi AP 扫描”，
  以便行车时约每 8 秒获取一批 AP。保留扫描通知；从最近任务划掉应用会结束采集。
  手机可能发热。放入口袋或整夜运行时应改用省电模式。


5. 界面内容
------------

实时
  通过雷达、信号列表、时间线、混合视图或按类别显示，查看空中无线信号。
  可调整每条列表记录的信息量。圆形图标表示设备类别，未匹配时显示“?”。
  副标题前的小 Wi-Fi 或蓝牙图标表示接入点 / BLE 广播设备；不使用 AP / LE 字母标签，
  也不会将该图标移到主标题。点击右上角调节图标打开“显示”，调整后可收起。

  视图
    雷达、信号列表、时间线、混合视图、按类别。
    “按类别”的层级为：类别 A–Z → 特征 A–Z → 无线设备 → 详情。
    “显示全部”保留空类别，“折叠空类别”隐藏数量为零的类别，相关选项随列表滚动。
    设备记录使用与列表相同的显示开关和类别图标。
    关注列表命中时，会播放已启用的提示音和 / 或语音，并展开对应类别与特征以突出显示记录。
    距离足够近时，自动跳转会将相关标题保留在屏幕内。
    雷达目标先闪烁，再保留荧光圆环；列表记录会在本次会话中保留荧光铃铛。

  排序
    最强信号、30 秒平均最强信号（默认）、最近接收、最新提醒、最新出现、
    新设备置底、名称 A–Z（使用标题行）、特征优先。
    排序只改变顺序，不隐藏设备。“新设备置底”将新记录放到末尾；
    “最新提醒”将最近的关注命中置顶，并保留荧光铃铛。

  短暂保留
    可关闭，或在最后一个数据包后继续保留记录 10 / 30 / 60 秒。

  标题行
    广播名称、名称 + 类型、MAC（默认）。

  副标题
    与标题行相同，也可选“无”隐藏第二行；随机地址 / 已离开状态会移到标题行。
    Wi-Fi 或蓝牙图标只位于副标题，不会移到标题。
    默认“名称 + 类型”；未命名 BLE 会显示为“未命名”。

  附加开关
    RSSI 条、特征名称、频率（RSSI 下方的信道和 MHz）、首次 / 上次发现。

  “筛选”决定显示哪些设备，“显示”决定每条记录显示多少信息。
  制造商 / 厂商信息位于详情页。“Apple, Inc. · AirTag…”之类的副标题来自“名称 + 类型”
  （其中类型是推测），IEEE 厂商请查看详情页。
  在拥挤广场可将副标题设为“无”并关闭附加信息；默认第一行已经是 MAC，便于复制。
  观测 Wi-Fi 信道时可开启频率。完整说明见用户手册 §5.3。
  已在实时页时，再次点击“实时”可暂停画面；扫描和日志继续运行，恢复时仍应用筛选。
  再次点击“实时”恢复列表。开启“仅新发现”后，页面会显示提示，
  并在底部标签栏上方提供“标记已见 / 重置已见”。

筛选
  位于“实时”旁边，用于决定哪些设备出现。
  顶部预设每行两个，点击会替换整套筛选；“将当前筛选另存为…”可保存命名副本。
  默认预设：全部信号、仅 Wi-Fi、仅 BLE、强信号（−70 dBm）、随行、仅已关注。
  “仅已关注”包括已关注的特征，以及开启提醒的命名设备。
  摄像头、无人机、寻物标签、手机、电脑等类别位于下方；可选择“仅显示”，
  再另存为命名预设。筛选只影响实时视图，匹配始终会标记。
  “随行”位于“要显示的无线设备”下方，其下是“仅新发现”。
  “仅特征匹配”“仅已关注”“仅命名设备”位于类别选项上方。
  “仅已关注”仍受“隐藏这些”规则影响。
  开启“随行”会开始 BLE 跟随检测，Wi-Fi AP 不参与，因为覆盖范围可能看起来像同行。
  同时清除“仅特征匹配”“仅已关注”“仅命名设备”和类别的“仅显示”，避免这些筛选清空列表。
  类别选项每行两个，与实时页使用相同图标。可选择“仅显示”或“隐藏这些”。
  “仅显示”未选类别时不会隐藏未匹配设备；选中类别时“仅特征匹配”自动开启并变灰。
  “隐藏这些”保留未匹配设备，此时“仅特征匹配”仍可独立切换。
  “隐藏所选”可隐藏某个系列（例如包里的 AirTag）；“仅显示所选”只保留选中的系列。
  “隐藏 Fast Pair 账户密钥”（位于“仅命名设备”下）会移除只匹配到已配对 Fast Pair 的记录；
  配对模式仍保留，并显示“Fast Pair 配对”。商场内大量未命名 Fast Pair 是环境背景，
  不是 Android 身份。详见用户手册 §9.5。
  长按预设可删除。默认预设删除后，只有“恢复默认特征库和预设”才能恢复。
  “重置筛选”清空本页条件。详见用户手册 §8.4。

特征库
  保存带名称的匹配规则。圆形图标表示类别，与实时 / 筛选页一致。
  排序可选名称 A–Z（默认）或类别 A–Z；类别初始折叠，点击后展开特征。
  每个默认特征命中后都会标记。关注表示为命中启用提示音和 / 或类别语音。
  可在筛选页按类别“隐藏这些”，或“隐藏所选”，减少嘈杂系列。
  以下默认特征附带重点关注文字（实时页的“!”和详情卡片）并已关注：
    随身摄像头、摄像眼镜、可穿戴录音设备、渗透测试工具、公共安全车载 AP，
    路侧 / 公共摄像头和车牌识别设备（Flock、Penguin、Pigvision、FS Ext Battery、
    Genetec AutoVu、Rekor、Motorola Vigilant、Verkada、Avigilon、Axis、Hikvision、
    Dahua、Hanwha Wisenet、Uniview、Rhombus），以及 GhostESP / Bruce。
  Tesla、耳机、UniFi Protect、BlueTOAD Spectra、BlipTrack 和门禁锁默认不含这些提醒。
  如果某条自定义或旧版特征因通用模块 OUI 产生过多命中，可取消关注。
  当前 Flock 特征已将 LiteOn 等模块前缀拆分为独立摄像头无线模块特征。
  UniFi AP 仅匹配 Wi-Fi（Ubiquiti OUI 和出厂 SSID），属于“运营商 / 路由器”。
  独立的 UniFi 条目可匹配任一无线类型的广播名称，类别相同。
  UniFi Protect Instant 摄像头仍属于“监控设备”。
  园区 AP（Meraki、Cisco、Aruba、Ruckus、Ruijie、Fortinet、Mist、Sophos、
  Extreme、Edgecore、WatchGuard AP、Mojo）属于“运营商 / 路由器”，不属于监控设备。
  同时携带 Cisco 厂商 IE 的 Meraki BSSID 只保留 Meraki 标签。
  DWnet / WAVLINK / GL.iNet 94:83:C4 同样属于运营商类。
  未匹配的 Wi-Fi 常见于家庭网络名称、车载热点或随机 BSSID，不一定是遗漏的园区 AP。
  Roku 隐藏 Wi-Fi Direct 遥控 AP 通过厂商 IE C8:3A:6B 匹配“家庭物联网”。
  Franklin RG3100* / OUI 50:FB:FF 属于运营商 / 路由器（运营商 5G 网关）。
  Samsung [fridge]* / [oven]* 和 EcoWater H2O-xxxxxxxxxxxx 属于家庭物联网。
  编辑器中每条规则都有独立开关。
  BLE 条目可配置“解码字段”。匹配特征后，详情页将明文广播字节映射为标签，
  如 Ruuvi 温度、Remote ID 位置、GoPro 型号等。加密广播仍显示十六进制，不进行配对。
  根据载荷规范填写映射的方法见用户手册 §9.6.1–§9.6.5，默认映射见 §9.6.6。

  默认类别颜色（每个条目都可以修改）：
    红色：渗透测试 / 廉价串口模块，包括 GhostESP / Bruce。
    绿色：Mesh / LoRa，如 Meshtastic、MeshCore、Helium、goTenna、SenseCAP、RAK。
    琥珀色：摄像头 / 车牌识别 / 市政设备 / UniFi Protect / BlueTOAD / BlipTrack / DJI。
    紫色：手机 / Find My，如 Apple Device、Fast Pair、AirTags、Chipolo、Google。
    青色：可穿戴追踪设备 / 信标，如 SmartTag、Tile、iBeacon、Target Atrius 购物篮、Minew。
    橙色：眼镜和音频设备；颜色相同，类别不同。
    蓝绿色：公共安全（随身摄像头 / 公共安全 AP）和车辆；颜色相同，类别不同。
      公共安全类设备常用于执法，但并非执法专用；政府、市政及企业车队也可能使用相同装备。
    银色：消费级摄像头（Wyze / Ring / GoPro / Osmo / Insta360）、家庭物联网、
      运营商 Wi-Fi、温控器、Tuya、门禁、零售标牌及旧版未知特征。
  未匹配设备按 RSSI 着色，不按类别。完整特征库见用户手册 §9.5 和附录 B。

报告
  包含轨迹、观测总结、观测导出、对比、AI 导出、特征候选及日志导出。
  日志格式：CSV、JSON Lines、GPX（GPS 交换格式）、KML（Google Earth）、
  WiGLE CSV（wigle.net）；可选两者、仅 Wi-Fi 或仅 BLE，也可重置 / 清除日志。
  选中的观测决定轨迹、观测总结、观测导出及对比中“本次观测”的数据。
  观测导出：选定时段中每个独立无线设备一条记录，命名观测上限 6000 个，
  最近 15 分钟内存数据约 400 个。无需开启日志；GPX / KML 包含本手机的轨迹。
  日志导出：滚动会话文件，包含启用日志期间的每次接收。清除日志不会删除观测。
  Fieldwatch 不上传文件。观测总结 / 对比 / 轨迹 / GPX / KML 使用自定义设备名；
  WiGLE 仍保留广播 SSID。“观测备注”位于观测总结的“所在地点”之后，
  或对比报告的“观测时段”之后。
  对比观测：本次观测（与观测总结相同）对比第二次已保存观测。
  仅比较出现情况，以类型 + MAC 区分，并标出重点关注。
  最近 15 分钟与命名观测统计范围不同（内存约 400，命名观测 6000）。
  对比的 AI 导出生成补充分析（重合率、单次出现的重点关注 / 命名设备 / 观测备注），
  不重复设备清单。观测报告的 AI 导出仍只针对当前时段。
  未选择命名观测时，观测总结使用内存中最近 15 分钟数据，约 400 个无线设备，
  不读取日志。未命名 BLE 约 3 分钟后移除，命名设备约保留 15 分钟。
  行车时可每 10–15 分钟或在停留点生成总结；持续随行设备会在各报告中继续出现，
  已经过的路侧背景设备则不会一直保留。
  特征候选从滚动日志中查找未匹配系列，例如至少两个无线设备共享名称通配模式、
  厂商 IE、UUID 或 OUI。创建特征会生成带共同规则的草稿，不固定单个 MAC；
  保存后返回特征库。分享日志导出完整文件。
  GPS 同行分析分为寻物标签（可能随行的追踪器 / 可能尾随）、零售信标和可穿戴设备。
  观测 AI 导出用于补充变化速率、重点关注和追踪标识分析，不再列一份设备清单。
  日志开关和 GPS 位置标记仍位于“设置”。

设置
  扫描强度、加快 Wi-Fi AP 扫描、GPS 位置标记、在线地名和地图、保持屏幕常亮、
  日志开关及轮换大小、关注列表、命名设备（自定义名称 + 观测备注）。
  滚动日志文件为 JSON Lines；导出格式在“报告 → 日志导出”选择。
  页脚显示 Fieldwatch 版本和特征库版本。
  “从 GitHub 更新默认特征库”需要网络，会替换默认条目及重点关注说明，保留关注状态。
  上游特征库可能包含英文说明；离线可使用“导入特征库”。
  GPS 位置标记、在线地名和地图、保持屏幕常亮、关注提醒、提示音默认开启。
  当前版本的“关注特征语音提醒”也默认开启，默认播报“类别 + 特征”。
  提示音与语音互相独立，可以只响一声、只播报或同时启用。
  开启语音后，“播报内容”可选类别、特征、类别 + 特征。
  类别如寻物标签、音频；特征是特征库条目名称，如 Apple AirTags、Axon。
  这不是信号追踪提示音。“测试提醒”播放当前启用的内容。
  自动跳转适用于提示音、语音或两者同时开启的情况。
  “加快 Wi-Fi AP 扫描”默认关闭。先关闭系统“开发者选项 → Wi-Fi 扫描节流”，
  再开启应用开关（Android 11+；Fieldwatch 会先检查系统标志）。
  这样约每 8 秒而非约 30 秒获取一批 AP，行车时更有机会捕获已知特征 AP
  （IBR*、AirLink、UniFi、Cisco、隐藏的车队 MAC）。
  隐私模式默认关闭。开启后，屏幕、观测总结、AI 导出及设备详情文字分享中的
  MAC 最后三个字节显示为 **:**:**，GPS 上次定位及观测报告坐标显示为“已隐藏”，
  街道名称被省略，TAK / CoT 发送暂停。日志仍保留完整数据。
  地图瓦片由“在线地名和地图”控制；当前版本的隐私模式不会隐藏这些地图。
  列表显示方式仅在“实时 → 显示”调整，不在设置页。

详情
  点击实时记录进入。右上角关注按钮关注此 MAC，直到手动关闭；设备离开后也不会取消。
  若匹配特征带有重点关注文字，将显示对应卡片。
  可以“以文字分享”，也可 AI 导出针对这个无线设备的分析提示。
  BLE 匹配到解码映射时显示解码字段，如温度 / 型号 / Remote ID（手册 §9.6）。
  已保存的自定义名称作为大标题，广播名称以较小文字显示。
  青色观测备注位于名称下方。BLE 随机 / 隐私 MAC 不提供自定义名称与备注编辑。
  BLE 的“信号追踪”根据强弱变化提示更近或更远；“您”周围的圆环会相应收缩或扩大。
  信号约达到 −45 dBm 或更强时提示“非常近”。
  底部提示音 / 振动默认关闭，开启后会随 RSSI 增强而加快，但不能换算为米。
  可选：将手机贴近胸前，用身体遮挡一侧并缓慢转身。
  信号较强的朝向可作为粗略候选方向，然后移动观察。
  墙壁和金属会改变 RSSI，即使实际距离没有变化。详见手册 §12.8 / §12.13。

Wi-Fi 记录仅包含接入点：路由器、热点、Mesh 节点、手机热点。
使用 Wi-Fi 但没有广播网络的手机不会出现。
默认第一行是 MAC，第二行以 Wi-Fi 或蓝牙图标开头，随后显示名称 + 类型
（SSID、BLE 名称或推测类型）。右侧数字是 RSSI，单位 dBm。
模式匹配不能证明身份。“随行”和观测总结的跟随分析属于基于信息的推测，不是法律结论。


6. 现场快速开始
----------------
  • 开始几分钟使用“设置 → 扫描强度 → 高性能”。
    行车观测已知特征 AP 时，先关闭“开发者选项 → Wi-Fi 扫描节流”，
    再开启“设置 → 加快 Wi-Fi AP 扫描”（手册 §7.1.1 / §10.3.1）。
  • 实时页选择信号列表和全部信号，按任务调整显示。
    人群中可隐藏副标题；Wi-Fi 观测可开启频率。
  • 特征命中始终标记。在筛选页按类别“隐藏这些”或“隐藏所选”减少背景信息。
    默认关注已涵盖随身摄像头、Meta / Snap 眼镜和渗透测试设备。
    当前版本默认开启提示音和语音，可在设置中分别调整。
    播报内容默认“类别 + 特征”，也可只选类别或特征。“测试提醒”播放当前内容，
    与信号追踪无关。
  • GPS 位置标记、保持屏幕常亮、在线地名和地图默认开启。
    开启系统高精度定位，步行 / 驾车直至筛选页显示非零轨迹，再开启“随行”。
    该筛选寻找信号较强且稳定的随行设备（包 / 车内标签，不是另一台 iPhone 的身份）。
    移动后，“报告 → 观测总结”仍保留最近 15 分钟的追踪分析，
    即使已离开该筛选，或切换到雷达 / 时间线。
  • 观测房间：开启“筛选 → 仅新发现”，待环境成为基线后，在实时页点击“标记已见”。
  • 点击实时记录，可文字分享、AI 导出，或对 BLE 进行信号追踪，根据信号强度移动。
    身体遮挡并转向只能提供粗略候选朝向；墙壁、金属和楼层可能在距离不变时改变 RSSI。
    不能换算为米。详见手册 §12.8 / §12.13。
  • 查看未知追踪设备：在筛选页仅显示寻物标签，隐藏自有标签，
    将手机靠近可能放置设备的位置（各车轮、保险杠、车厢）。
    若某记录跃到顶部，可打开信号追踪并重复观察。
    没有信号不代表区域已确认无设备。详见 §12.8。
    若要查看某设备是否持续随行，即使已离开寻物标签筛选，
    观测总结仍包含最近 15 分钟的相关检测。
  • 约每 15 分钟，或行车途中每个停留点，生成“观测总结（文字）”或“观测总结（PDF）”。
    保存这些分享文件；每份只覆盖对应时段，并非整段行程。
    城市环境中几千米内可能填满约 400 个实时设备，未命名 BLE 约 3 分钟后就会移除。
    持续随行的设备（包内标签、汽车胎压传感器、被放置的追踪器）会被持续接收，
    因而保留到下一份总结。AI 导出包含设备内观测总结和工作数据，
    请求聊天模型补充统计分析，不重写原报告。
    开启在线地名和地图且手机联网时，报告可包含街道名；隐私模式会省略它们。
    实时视图与筛选不改变观测总结。“分享日志”和“保存到 SD 卡”在同一标签页。
  • 完整的事后记录：使用“报告 → 分享日志”，采集时必须已开启日志。
    开启 GPS 标记后，新日志包含 lat,lon（接收时手机的位置）；
    新 Wi-Fi 记录还包含 vendor_ie（以竖线分隔的厂商 IE OUI）。
    需要已被 15 分钟观测总结丢弃的记录时，使用日志。
  • 日志中的未匹配系列：使用“报告 → 特征候选”。
    它寻找至少两个无线设备共享的名称通配模式、厂商 IE 或 OUI。
    创建特征并保存，并非每个未知设备都能成为候选。
    厂商 IE 系列需要包含相应数据的日志记录。

关于步行随行、房间新增设备、BLE 信号追踪、隐藏背景、摄像头观测、重点关注、
渗透测试设备和读卡器提示，以及对应报告入口，请参阅用户手册第 12 章“现场操作指南”。


7. 卸载
--------
  Android 设置 → 应用 → Fieldwatch → 卸载。
  卸载会删除日志和配置。需要保留时，请先将分享日志或观测总结保存到手机之外。


能力限制
--------
  • 原生 Android：无法捕获 Wi-Fi 客户端或仅发出探测请求的终端，不支持 802.11 监听模式。
  • 仅接收 BLE 广播，不执行经典蓝牙查询；HC-05 / HC-06 不会出现。
  • 不监听蜂窝网络。静默或仅使用蜂窝网络的摄像头杆可能始终不出现。
  • 不进行无线测向。RSSI 是信号强度，不是距离。
  • 实时列表通常保留约 400 个无线设备（硬上限 900）。
    未选择命名观测时，观测总结读取同一份内存数据，不读取日志；行车时应多次生成总结。
  • 侧载版本未经 Play 签名，不会自动更新。
